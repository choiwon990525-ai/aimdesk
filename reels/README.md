# reels/ — 인스타 릴스 분석

**에임데스크 사이트와 무관합니다.** 사이트 파일을 하나도 건드리지 않고, 배포에도 안 들어갑니다.

Apify 로 릴스를 모으고 → 조회수·참여율을 묶음별로 정리하고 → (선택) Gemini 로
잘 된 릴스와 덜 된 릴스를 비교합니다. 표준 라이브러리만 쓰는 파이썬 파일 하나라
설치할 것이 없습니다 (Python 3.8 이상).

## 쓰는 법

```
python reels/reels.py collect --tag 티원 --tag 롤 --limit 30        해시태그·키워드로 모으기 + 분석
python reels/reels.py collect --url https://www.instagram.com/t1lol/  계정 릴스 모으기 + 분석
python reels/reels.py usage                                          이번 달 사용량 · 최근 실행 ID
python reels/reels.py import xVQotGdt3G4XWwVxI jmIMXDEnEOEc4PMa0     이미 돌린 실행을 가져와 분석
python reels/reels.py analyze reels/out/20261021-222133-t1 --ai      다시 분석 + Gemini 요약
```

| 옵션 | 뜻 |
|---|---|
| `--tag` | 해시태그·키워드. 여러 번 쓰거나 쉼표로 (`--tag 티원,롤`) |
| `--exact` | 키워드 검색 대신 해시태그 페이지만 본다 (기본은 키워드 검색 — 지금까지 Apify 에서 쓰던 방식) |
| `--url` | 계정 URL · 아이디 · 릴스 URL |
| `--limit` | 태그·계정마다 최대 개수 (기본 30) |
| `--max-usd` | 이번 수집 비용 상한 (기본 0.5) — Apify 가 서버에서 끊습니다 |
| `--shares` `--transcript` | `--url` 수집에 공유 수 · 음성 전사를 붙인다. **유료 추가 옵션** |
| `--ai` · `--model` | Gemini 요약 (기본 `gemini-flash-latest`) |
| `--name` | 결과 폴더 꼬리표. 영문만 — 한글 폴더명은 윈도우에서 깨집니다 |

## 키

환경변수 `APIFY_TOKEN` · `GEMINI_API_KEY`. 클라우드 세션처럼 프록시가 키를 넣어 주는 곳에서는 없어도 됩니다.

```
set APIFY_TOKEN=...            (cmd)
$env:APIFY_TOKEN="..."         (PowerShell)
export APIFY_TOKEN=...         (맥 · 리눅스)
```

## 비용 (2026-10-21 Apify 가격표에서 읽은 값 · Free 등급)

| | 1개당 |
|---|---|
| 태그 수집 · URL 수집 | $0.0026 |
| `--shares` 공유 수 | +$0.007 |
| `--transcript` 음성 전사 | **+$0.048** — 기본 수집의 18배 |

Free 플랜은 월 $5 이니 태그 수집만이면 약 1,900개입니다. 실행 전에 **가격표를 API 로 직접 읽어**
예상 최대 비용을 보여주므로 위 표가 낡아도 화면의 숫자가 맞습니다.

`import` 는 이미 받은 결과를 다시 내려받는 것이라 추가 과금이 없습니다.
**단 Free 플랜은 결과를 7일만 보관합니다** — 지나면 `import` 가 실패합니다. `collect` 는 바로 로컬에 저장하니 상관없습니다.

## 결과

`reels/out/<시각>-<꼬리표>/`

| 파일 | |
|---|---|
| `report.html` | 보고서 — 브라우저로 여세요 |
| `reels.csv` | 릴스 한 줄씩. 엑셀에서 한글이 안 깨지게 BOM 을 붙였습니다 |
| `raw.json` · `meta.json` | Apify 원본 · 실행 기록. `analyze` 는 이 둘만 있으면 다시 돕니다 |
| `ai.md` | `--ai` 요약. 다음에 `--ai` 없이 다시 분석해도 이걸 그대로 씁니다 |

**`out/` 은 git 에 안 올립니다** (`.gitignore`). 남의 계정 이름·캡션·댓글이 들어 있고 저장소가 public 입니다 —
`research/` 를 안 올리는 것과 같은 이유입니다.

## 지표 — 무엇을 어떻게 셌나

| | |
|---|---|
| 조회수 | 재생 수 (`videoPlayCount`). **수집 시점 누적값** |
| 하루 조회수 | 조회수 ÷ 경과일 (최소 1일) |
| 참여율 | **(좋아요 + 댓글) ÷ 조회수** |
| 공유율 · 저장율 | 따로 냅니다. 일부 릴스에만 있어서 참여율에 섞으면 같은 자로 잰 값이 아니게 됩니다 |

- 대표값은 **중앙값**입니다. 한두 개 터진 릴스가 평균을 끌어올립니다
- **n < 5 인 묶음은 흐리게** 두고 「보류」를 붙입니다. 값은 보이지만 판단하지 마세요
- 같은 릴스가 여러 출처에 걸리면 하나로 합칩니다. 빈 칸은 다른 실행의 값으로 채웁니다
  (저장 수는 `data-slayer~instagram-post-details` 결과에만 있습니다)
- 좋아요를 숨긴 릴스는 -1 이 옵니다 — 0 으로 세지 않고 빈 값으로 둡니다

길이 · 요일 · 시간대 (KST) · 원본 오디오 대 음원 · 참여 유도 문구 · 캡션 길이 ·
함께 쓰인 해시태그 · 두 번 이상 나온 계정 · Gemini 요약 · **읽을 때 주의**

Gemini 는 **캡션과 지표만** 봅니다. 영상은 안 봅니다. 주장마다 근거 릴스를 2개 이상 달게 했고,
본문의 shortCode 는 릴스 링크로 바뀝니다 — 열어서 맞는지 확인하세요.

## 읽을 때 주의

- **표본이 무작위가 아닙니다.** 인스타 검색·프로필 결과라 인기·최신 쪽으로 쏠려 있습니다
- **오래된 릴스는 조회수에, 최근 릴스는 하루 조회수에 유리합니다.** 둘을 같이 보세요
- 모든 비교는 상관입니다. 「짧으면 조회수가 높다」가 보여도 짧게 만들어서 높아졌다는 뜻은 아닙니다
