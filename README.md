# 에임데스크 (AIMDESK)

FPS 감도 변환기와 자세 가이드. **정적 파일 네 개가 전부입니다** — 빌드 도구도 백엔드도 없습니다.

## 하는 일 두 가지

**① 감도 변환** — 게임이나 DPI가 바뀌어도 **cm/360** 하나를 그대로 옮깁니다.
한 바퀴 도는 데 마우스가 실제로 움직이는 거리가 그 값입니다.
감도 숫자는 게임마다 다르지만 손이 움직이는 거리는 하나입니다.

**② 자세 가이드** — 직접 잰 값으로 측면도를 그리고 좌면·책상·눈높이의 목표를 냅니다.
**키에서 비율로 추정하지 않습니다.** 안 잰 값은 「재야 나옵니다」로 비워 둡니다.
**점수도 등급도 내지 않습니다.**

## 근거 등급 — 이 사이트의 존재 이유

모든 수치에 **어디까지 확인됐는지**를 답니다. 색은 **오직 확신의 정도에만** 씁니다 —
버튼에도 링크에도 강조에도 색을 안 쓰는 이유가 그것입니다.

| | 뜻 |
|---|---|
| 🟢 **검증** | 출처에서 확인됐고 교차검증을 통과했습니다 |
| 🟡 **추론** | 방향은 맞지만 수치는 다른 맥락에서 옮겨온 것입니다 |
| 🔴 **미지원** | 출처가 갈리거나 없습니다. **모른다고 적습니다** |

자세 가이드에는 ⬜ **절차** 태그가 하나 더 있습니다. 근거 등급이 아니라
**숫자를 주장하지 않고 자기 몸에서 확인하는 방법**이라 무채색으로 분리했습니다.

**모르는 값은 비워 둡니다.** 그럴듯한 숫자로 채우면 나머지 초록도 같이 의미를 잃습니다.
Apex 1× 조준 슬라이더가 지금 그렇게 비어 있고, 「일부러 안 넣은 것」 섹션이
뺀 기능들과 **무엇이 채워지면 돌아오는지**를 전부 적어 둡니다.

## 띄우기

```
python3 -m http.server
```

```
index.html      감도 변환기
posture.html    자세 가이드
styles.css      스타일 (두 페이지 공용)
app.js          계산 · 렌더 · SVG 생성 (두 페이지 공용)
```

`tools/` 는 검사 전용이라 배포에 안 들어갑니다 — 실제 브라우저로 렌더해서
명도 대비·탭 타겟·요소 가림·SVG 라벨 이탈을 잽니다.
`research/` 는 원본 근거 자료이고 읽기 전용입니다.
